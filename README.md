### 📌 Featured Machine Learning Projects

#### 🔥 [Driving Behavior Classification Pipeline](https://github.com/adel-mahmoud-elazawy/NTI_Final_project_driving_behavior_pipeline)
> **Complex sensor-based classification system using Motion Accelerometer & Gyroscope data.**
> - **Highlights:** Advanced feature engineering (Magnitude calculations, rolling window statistics, segment-based dt), leak-free preprocessing pipeline.
> - **Models Compared:** KNN, SVM, Decision Trees, Random Forest, XGBoost, LightGBM, AdaBoost.
> - **Built with:** `Python` • `Scikit-Learn` • `XGBoost` • `LightGBM` • `Pandas` • `NumPy`

<br />

#### 📈 [Adult Income Prediction — Binary Classification](https://github.com/adel-mahmoud-elazawy/-KNN_LogisticRegression_NaiveBayes_Classifier_Adult-)
> **Predicting census income levels (>50K vs <=50K) using UCI demographic dataset.**
> - **Highlights:** RobustScaler, stratified splits, `net_capital` feature creation, hyperparameter tuning with 5-Fold Cross-Validation.
> - **Best Result:** KNN ($K=31$) achieved **86.27% Accuracy** & **0.915 ROC-AUC**.
> - **Built with:** `Python` • `Scikit-Learn` • `Pandas` • `Seaborn`

<br />

#### 🚗 [Car Evaluation Acceptability Classifier](https://github.com/adel-mahmoud-elazawy/Car-Evaluation-Acceptability-Classifier)
> **Multi-class acceptability prediction using structural & economic car features.**
> - **Highlights:** Ordinal feature encoding, Decision Tree `max_depth` pruning, and Random Forest ensemble analysis.
> - **Built with:** `Python` • `Scikit-Learn` • `Matplotlib`

<br />

#### 🏡 [House Price Prediction — Linear Regression](https://github.com/adel-mahmoud-elazawy/House-price-LinearRegression-)
> **Predicting King County housing prices through a comprehensive regression workflow.**
> - **Highlights:** EDA, skewness transformation via `log1p`, One-Hot Encoding for zipcodes, Ridge & Lasso Regularization ($R^2 \approx 0.778$).
> - **Built with:** `Python` • `Scikit-Learn` • `Pandas` • `Matplotlib`

<br />

#### 💼 [Facebook Live Engagement Clustering](https://github.com/adel-mahmoud-elazawy/Facebook_Live_Engagement_Clustering.ipynb)
> **Unsupervised Segmentation of Facebook live streams based on engagement metrics.**
> - **Highlights:** Log transformations, Elbow Method & Silhouette Score for optimal $K$, and 2D PCA visualization.
> - **Built with:** `Python` • `Scikit-Learn` • `PCA` • `Seaborn`
